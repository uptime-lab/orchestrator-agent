# Security policy (agent mirror)

The agent runs as root on managed devices, so a defect in it is a device
compromise. Report a vulnerability through this repository's private
vulnerability reporting, or to `security@orchestrator.sh`. Do not open a
public issue.

What to expect: an acknowledgement within three business days, a fix in the
next agent release, and a GitHub Security Advisory once the release is on the
update channel. Self-hosted operators learn of a fix when the release ships;
there is no advance notice until a platform release pipeline exists.
